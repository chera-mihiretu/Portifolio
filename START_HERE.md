## 🚀 Quick Deploy Commands

```bash
# 1. Push to GitHub
git add .
git commit -m "Add comprehensive SEO optimization with credentials"
git push origin main

# 2. Deploy to Vercel (via dashboard or CLI)
# Visit vercel.com and import your repo
# OR use CLI:
npm i -g vercel
vercel

# 3. After deployment, update domain in:
# - src/app/layout.tsx (line 19)
# - src/app/sitemap.ts (line 4)
# - public/robots.txt (line 8)

# 4. Redeploy
git add .
git commit -m "Update production domain"
git push origin main
```
